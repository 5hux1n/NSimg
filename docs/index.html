Chrome / Edge 扩展

Manifest V3 扩展，支持文件选择、粘贴和拖拽上传。

下载扩展 ZIP ↓
  1. 解压到固定目录。
  2. 在扩展页面开启开发者模式。
  3. 加载已解压的扩展程序。

尚未发布到扩展商店；v1.0.2 仍需浏览器实测。

{ }

独立用户脚本

用于支持用户脚本的浏览器或管理器，包括 Alook 与 Safari + Userscripts。

下载用户脚本 ↓
  1. 导入脚本。
  2. 允许在 nodeseek.com 运行。
  3. 刷新编辑器，使用图片入口。

Alook 上传流程已有真机测试；其他环境按 README 查看验证状态。

需要自己填写 NodeImage API Key 吗？

如果无法自动获取，在扩展弹窗或用户脚本的图库设置中填写并保存。已有 API Key 的上传无需依赖 NodeImage 登录会话。

以前上传的图片还能找回来吗？

从图库中查看缩略图、打开原图，再次插入帖子或删除图片。确认编辑器已写入后才显示插入成功。
