浏览器扩展 · 用户脚本

图片上传，就在编辑器里。

在 NodeSeek 原生编辑器中上传、插入和管理 NodeImage 图片。粘贴截图、选择图片，或从历史图库找回链接，继续写你的帖子。

下载与安装 ↗阅读项目说明 ↗

当前未发布到浏览器扩展商店。独立 JS 的 Alook 上传流程已通过用户真机测试，其他环境的当前版本仍需进一步复测。

项目能做什么

快速上传

粘贴截图或批量选择图片，上传后依次插入 Markdown 图片链接；扩展版支持拖拽。

历史图库

查看缩略图、打开原图，将已有图片插入编辑器，或删除不再需要的图片。

原生体验

复用 NodeSeek 的图片按钮与界面颜色，保持原有发帖和回复流程。

开始使用

  1. Chrome / Edge：下载扩展 ZIP、解压，在扩展管理页面开启开发者模式并加载解压目录。
  2. 独立 JS：下载用户脚本，导入兼容浏览器或脚本管理器，允许在 nodeseek.com 运行。
  3. 刷新发帖或回复编辑器并上传图片。若无法自动获取 Key，在设置中填写自己的 NodeImage API Key。

完整说明、兼容范围与最新状态见 项目 README。问题反馈请前往 GitHub Issues。
